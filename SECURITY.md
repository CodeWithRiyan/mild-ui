# Security Policy

## Supported versions

Security fixes are released for the latest published minor version of `@mild-ui/core`, `@mild-ui/react`, `@mild-ui/vue`, `@mild-ui/tokens`, and `@mild-ui/primitives`. The five packages always share one version number.

## Reporting a vulnerability

**Do not open a public issue for security problems.**

Report vulnerabilities privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability** (<https://github.com/CodeWithRiyan/mild-ui/security/advisories/new>). Only the maintainers can see the report.

Please include:

- the affected package(s) and version(s),
- a description of the issue and its impact,
- steps or a minimal reproduction.

## What to expect

- **First response within 7 days** of your report, confirming we received it and whether we can reproduce it.
- Status updates at least every 14 days until the issue is resolved.
- Once a fix is released, we publish a GitHub Security Advisory and credit you, unless you prefer to stay anonymous.
