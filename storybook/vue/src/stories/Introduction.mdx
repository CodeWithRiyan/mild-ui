# @mild-ui/vue

Vue 3 components for the mild-ui design system: styled by `@mild-ui/core`, driven by the
framework-agnostic `@mild-ui/primitives`, and mirrored one-to-one by
[`@mild-ui/react`](https://codewithriyan.github.io/mild-ui/react/).

```bash
npm install @mild-ui/vue @mild-ui/core
```

```vue
<script setup lang="ts">
import "@mild-ui/core/mild-ui.css";
import { ThemeProvider, Button } from "@mild-ui/vue";
</script>

<template>
  <ThemeProvider>
    <Button>Get started</Button>
  </ThemeProvider>
</template>
```

## What every component guarantees

- **Behaviour from the primitives.** Roles, `aria-*` attributes and keyboard handling come from
  `@mild-ui/primitives`, following the WAI-ARIA Authoring Practices patterns; every interactive
  story links its pattern and the test that enforces it.
- **Server rendering.** Every component renders with `vue/server-renderer` and hydrates without a
  warning (Nuxt ready).
- **Size budget.** Each export is bundled on its own and gzipped; the budget is enforced in CI.
- **Theming.** Light and dark modes through `<html data-theme>`; switch with the **Theme** toolbar
  above any story.
