Two frameworks, the same DOM.

mild-ui ships the same accessible components for React and Vue. Behaviour lives in framework-agnostic primitives, styling in one stylesheet, and every component renders identical markup for identical props, so a team can mix both and ship one look.

Built on four principles

Primitives first

Checkbox, Select, Dialog, Tabs and friends do not implement roles or keys themselves. They bind @mild-ui/primitives, so both frameworks behave the same.

Accessible by default

WAI-ARIA Authoring Practices patterns, linked from every story. Focus management, live regions and labels are part of the component, not an afterthought.

Tokens, not magic numbers

Spacing, color, radius and type come from --mild-* custom properties. Override the theme once; every component follows.

Ship only what you use

One file per module and side-effect-free JavaScript, so a bundler keeps the components you import. A gzip budget per export is checked in CI.

Get started in a minute

React

Vite, Next.js App Router, Remix: the package is a Client Component boundary. 

// npm i @mild-ui/react
import "@mild-ui/react/styles.css";
import { ThemeProvider, Button, Input } from "@mild-ui/react";

export function App() {
  return (
    <ThemeProvider>
      <Input placeholder="Your name" />
      <Button>Get started</Button>
    </ThemeProvider>
  );
}

Vue

Vite or Nuxt: import the core stylesheet once, then the components. 

// npm i @mild-ui/vue @mild-ui/core
<script setup lang="ts">
import "@mild-ui/core/mild-ui.css";
import { ThemeProvider, Button, Input } from "@mild-ui/vue";
</script>

<template>
  <ThemeProvider>
    <Input placeholder="Your name" />
    <Button>Get started</Button>
  </ThemeProvider>
</template>
